# P2 Feature and Model Foundation Plan

> For agentic workers: use the Superpowers execution flow and complete this plan task-by-task with failing tests before implementation.

## Goal

Move from the merged P1 evaluation spine to P2 model readiness: as-of-safe features, stronger baselines, model matrix, candidate model, ensemble, hierarchy reconciliation, and an FVA gate.

## Constraints

- TDD only: failing test, minimal implementation, refactor.
- All historical features must be as-of-safe.
- Known-future covariates must be explicit: promo calendar, prices, lifecycle flags, and static dimensions.
- The same feature builder must serve backtest and future prediction.
- No dashboard or business UI until P2 passes a positive FVA gate against MovingAverage8w.

Steps:
- [ ] RED lag leakage test: current target must not appear in lag_1; a future target spike must not change earlier features.
- [ ] GREEN groupwise shifted lag features by country/channel/sku.
- [ ] RED rolling leakage test: rolling values use only shifted historical target.
- [ ] GREEN rolling mean/std features.
- [ ] RED future promo join test: promo fields can join by week without target leakage.
- [ ] GREEN allowlisted promo/price join.
- [ ] RED lifecycle/static feature test.
- [ ] GREEN product/channel joins and product age.
- [ ] Run `python -m pytest tests/features/test_build_features.py -q`.
