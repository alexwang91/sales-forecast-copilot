# 01 · 决策框架与信任策略

> 本文回答两个问题：(1) 我们到底改进**哪些决策、给谁用**；(2) 怎么**赢得高层信任**。
> 信任策略是本项目区别于"又一个预测模型"的核心，请优先阅读。

---

## 1. 决策—角色映射

| 决策（系统要改进的） | 主要使用者 | 系统提供什么 | 对应页面 |
| --- | --- | --- | --- |
| 未来 4 周能卖多少（sell-out） | 国家销售、产品经理 | P10/P50/P90 预测 + 模型对比 + 误差/bias | Forecast Workbench |
| 这周给渠道补多少（sell-in） | 供应链、分货 | 库存覆盖周数 + 建议 sell-in + 缺货/压货风险 | Inventory & Sell-in |
| 促销方案怎么选 | 销售、GTM | 多场景 sell-out 对比 + 库存消化 + 风险 | Promotion Simulator |
| 新品首批铺多少 | 新品上市团队 | Analog 首 4 周 P10/P50/P90 + 铺货建议 | Launch Planner |
| 整体经营态势 | 区域负责人、高层 | 总预测 + Top 风险 + 本周变化 + override 记录 | Executive Overview |

> 设计纪律：**每个页面服务一个明确角色的一个明确决策。** 不做"什么都能看但谁都不爱用"的大杂烩。

---

## 2. 现状基线（Baseline）——必须先量化

赢得信任的前提是先把"现状"量化出来，否则"好多少"无从谈起。在动手建模前，明确并记录现有流程：

- 现在的预测**是谁做的、怎么做的**？（销售拍脑袋 / Excel / 去年同期 / 简单移动平均？）
- 现有预测的**历史误差**是多少？（如果连这个都没人统计过，这本身就是项目的第一个价值点。）
- 现有流程的**痛点**：滞后？口径不一致？无法复盘？缺货/压货频发？

> 这些信息进入 `09-open-questions` 与干系人确认。**没有量化现状，就不要开始建模。**

---

## 3. 信任策略：Shadow Mode 试点（最重要）

> 让高层信任一个新系统，最低风险的路径不是"上线替换"，而是**并行影子运行**。

### 3.1 做法

1. 选 **1 个友好国家**（本地销售负责人愿意当早期采用者）作为试点。
2. 系统**与现有人工流程并行**产出预测，**不改变任何真实决策**（shadow mode）。
3. 连续运行 **6–8 周**，每周冻结（freeze）双方的预测与当时可见的信息。
4. 周期结束，用 **FVA** 对照：系统 vs 人工 vs 朴素 baseline，谁更准、在哪些 SKU/渠道更准、风险预警是否命中。
5. 用这份**对照报告**去向高层汇报，而不是用"模型很先进"去汇报。

### 3.2 为什么有效

- **零风险**：影子模式不动真实发货/促销，决策权完全在人手里，消除"AI 乱来"的恐惧。
- **用事实说话**：6–8 周的并行对照是不可辩驳的证据，远胜任何 PPT。
- **把人变成盟友**：销售看到的是"AI + 我的判断，并且有人记录谁更准"，而不是"AI 要取代我"。

### 3.3 退出标准

- 若 FVA 为正且销售愿意参考 → 进入有限的真实使用（仍 human-in-the-loop）。
- 若 FVA 不为正 → 不上线，回到数据/特征/模型迭代，**绝不带着负 FVA 强推**（会永久损害信任）。

## 4. 信任的四根支柱

整个系统围绕"让高层敢信"来设计，对应四个可落地的产品能力：

| 支柱 | 含义 | 在系统里的体现 |
| --- | --- | --- |
| **可解释** | 每个数字都能追到来源 | Agent 解释层，每条结论带字段级来源（见 `07`） |
| **可追责** | 每次人工修改有人、有原因、有时间 | `forecast_override` 表 + 审计（见 `03`/`06`） |
| **可复盘** | 历史预测好不好可以回看 | rolling backtest + FVA 看板（见 `06`） |
| **可证明** | 比现状好多少有数字 | FVA 对照表是看板的信任核心（见 `06`） |

---

## 5. 汇报叙事（给高层的一页话）

最终向高层呈现时，叙事应是：

> "我们没有做一个更复杂的模型。我们做了一个能回答'比你们现在做法好多少'的系统。
> 在试点国家并行运行 8 周：人工流程 WAPE 28%，本系统 17%；
> 它提前预警了 N 次缺货、M 次压货；每个数字都能点开看到来源；
> 销售可以改预测，但每次修改都被记录、事后被复盘。
> 我们建议下一步把它扩展到 X 个国家，仍然是辅助决策、人做最终决定。"

> 注意这段话里**没有任何模型名词**。模型是手段，信任与价值是目的。
